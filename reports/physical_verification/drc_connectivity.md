# Physical Verification — RISC-V

The SCL report states that DRC and connectivity verification were part of the implementation methodology. The report provides a clean numerical DRC/connectivity result for the **4-bit counter** example, but not an equivalent clean numerical result in the RISC-V result section.

Therefore the RISC-V repository does **not** claim a numerical RISC-V DRC/LVS result.

| Check | RISC-V public status |
|---|---|
| Innovus DRC | Not available as a clean RISC-V-specific numerical result |
| Connectivity | Not available as a clean RISC-V-specific numerical result |
| LVS | Not available |
| GDSII | Report states layout was prepared for GDSII generation; GDS database not supplied |
