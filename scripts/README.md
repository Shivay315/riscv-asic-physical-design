# Reference Scripts

The scripts in this directory are **reconstructed/public reference flows**, not the original SCL scripts. The internship report explicitly records the major Genus and Innovus stages and commands, but the complete original implementation scripts were not supplied for public redistribution.

They are included because an interview-quality repository should show that the author understands the execution order and signoff hooks without falsely claiming to possess the original internal automation.

The original `script.tcl` supplied with the internship material was an older Cadence RTL Compiler-style synthesis script; its relevant flow concepts are preserved in the documentation but the internal paths and proprietary library references are not published.
